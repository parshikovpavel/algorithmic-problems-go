# Проверить валидность скобочной последовательности

## Условие

Дана строка, содержащую скобки только одного типа`(` и `)`. Проверить, что строка является валидной скобочной последовательностью, т.е. скобки должны открываться и закрываться в правильном порядке.

Обратите внимание, что пустая строка также считается допустимой.

## Решение

Заводим счет круглых скобок `brackets` и перебираем символы строки:

- для открывающей скобки – увеличиваем счетчик на 1
- для закрывающей скобки – уменьшаем на 1

Строка будет валидна, если:

- при уменьшении счетчика `brackets` – он не станет меньше 0
- в конце `brackets == 0`

| #    | Время  | Память |
| ---- | ------ | ------ |
| 1    | `O(N)` | `O(1)` |

[Реализация](solution.go):

```php
func isValidBraketSeq(input string) bool {
	var brackets int

	for _, char := range input {
		switch char {
		case '(':
			brackets++
		case ')':
			brackets--

			if brackets < 0 {
				return false
			}
		default:
			return false
		}
	}

	return brackets == 0
}
```
