# Кибербезопасность

## Условие

На работе у Васи требуют менять пароль каждую неделю, причём новый пароль не должен совпадать ни с одним из предыдущих. Любимый Васин пароль — это строка *s*, состоящая из строчных английских букв. Этот пароль он использует первую неделю. Придумывать и запоминать новые пароли Васе лень, поэтому он придумал правило, по которому он будет получать новый пароль каждую неделю:

- Берется исходный пароль *s*
- В данном пароле можно выбрать любую пару букв и поменять их местами
- Если такой пароль не совпадает ни с одним из тех, что уже были использованы, то этот пароль можно использовать

Определите, сколько недель Вася сможет генерировать новые пароли с учетом пароля s*s* на первой неделе.

## Формат ввода

Вводится строка s(1≤∣s∣≤10<sup>5</sup>), состоящая из строчных английских букв — начальный пароль Васи.

## Формат вывода

Выведите одно число — количество недель, в течение которых Вася сможет использовать исходный и измененные пароли.

### Пример 1

Ввод

```
abacaba
```

Вывод

```
15
```

### Пример 2

Ввод

```
aaaaaa
```

Вывод

```
1
```

## Решение

Суть задачи - найти количество однократных перестановок (двух пар) в строке при повторении символов. Нельзя переставлять более чем одну пару символов.

Алгоритм:

- постепенно идем по строке и добавляем очередной символ в перестановку
- т.к. переставлять можно только 2 символа, можем постепенно считать количество перестановок, наращивая длину строки
- вначале считаем количество перестановок для 2 символов, потом прибавляем количество перестановок с 3 символом и т.д.
- переставлять имеет смысл только отличающиеся символы, `количество возможных перестановок для каждого очередного символа = номер его позиции - кол-во раз который этот символ встречался раньше`

[Реализация](solution.go):

```go
func numPermutes(s string) int {
	// счетчик - сколько раз символ встречался раньше
	counters := make(map[byte]int)
	num := 0

	// идем последовательно по строке
	for i := range len(s) {
		// добавляем к текущему количеству перестановок, сколько перестановок с отличающимися символами можно сделать для текущего символа
		num += i - counters[s[i]]
		// счетчик повторений инкрементируем
		counters[s[i]]++
	}

	// нужно добавить 1 исходную перестановку
	return num + 1
}
```
